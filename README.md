# TouhouTweaks（NeoForge 1.21.1 移植版）

这是 TouhouTweaks 的 NeoForge 1.21.1 独立移植工程，原作者为 **H2Sxxa**，上游地址为：
<https://github.com/H2Sxxa/TouhouTweaks>

许可证保持 **GPL-3.0-only**。

## 功能

- 打开暂停菜单时播放暂停音效；
- 玩家死亡时播放死亡音效；
- 新获得漂浮或力量效果时播放对应音效；
- 截图时播放截图音效；
- 加载和加入世界界面显示“少女祈祷中……”；
- 崩溃报告随机加入车万风格 Witty Comment；
- 客户端配置和服务器总开关保留，并在登录、切换维度时同步。

## 构建信息

- Minecraft 1.21.1
- NeoForge 21.1.256
- Java 21
- Gradle 8+

构建产物为 `build/libs/touhoutweaks-1.5.0.jar`，放入 NeoForge 1.21.1 的 `mods` 文件夹即可。
